# Mini CRM Dashboard - Frontend

Frontend application for the Mini CRM Dashboard built with React and Vite.

## Features

* Admin login interface
* Lead management dashboard
* Add new leads
* Search leads
* Update lead status
* Delete leads
* Dashboard statistics
* Responsive UI
* Dark and light theme support

## Tech Stack

* React
* Vite
* Axios
* CSS

## Running Locally

```bash
npm install
npm run dev
```

The frontend communicates with the deployed backend API for lead management.

## Related Backend

The backend for this project is located in the `backend` directory of the main repository.
