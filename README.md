# Mini CRM Dashboard

A full-stack web application for managing client leads through a simple CRM dashboard.

## Overview

The application allows users to:

* Create and manage leads
* Update lead status
* Add follow-up notes
* Search leads
* View basic dashboard analytics
* Use dark and light themes

## Live Demo

**Frontend:** https://future-fs-02-gamma-mocha.vercel.app/

**Backend API:** https://future-fs-02-twwf.onrender.com

## Tech Stack

**Frontend**

* React.js
* CSS3
* Axios

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB Atlas

**Deployment**

* Vercel
* Render

## Features

* Admin login
* Create, read, update and delete leads
* Lead status management
* Search functionality
* Responsive dashboard
* Dark/light mode
* Basic analytics cards

## Running Locally

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
