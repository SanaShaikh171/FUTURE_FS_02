# Mini CRM Dashboard

A full-stack CRM dashboard for managing client leads, tracking lead status, and organizing follow-up information.

## Live Demo

**Frontend:**  
https://future-fs-02-gamma-mocha.vercel.app/

**Backend API:**  
https://future-fs-02-twwf.onrender.com

## Features

- Admin login interface
- Create and manage leads
- Update lead status
- Delete leads
- Search leads by name
- Add follow-up notes
- Dashboard statistics
- Responsive interface
- Dark and light theme support

## Tech Stack

### Frontend

- React
- Vite
- Axios
- CSS

### Backend

- Node.js
- Express.js
- Mongoose

### Database

- MongoDB Atlas

### Deployment

- Vercel
- Render
